# 目的を絞った顧問契約（目的ドリブン）

顧問やコンサルティングの仕事では、ご相談の幅が広がりやすくなります。だからこそ、お客さまごとに「この顧問で何を実現するか」を一つに決め、そこへ力を集めます。お客さまの目的をはっきりさせ、それを支え、そこから脱線しない。成果がお客さまにも自分にも見えやすくなり、続けやすい関係になります。

このキットでは、同梱のひな形 `komon-mokuteki`（顧問契約（目的を絞った月額顧問））と、CRM のメモ・やりとり・フォローを使って、この進め方を回せます。貼り付けて使うプロンプトは [PROMPT.md](../PROMPT.md) にあります。

## 五つの考え方

### 1. 目的は一つ、お客さまの言葉で

「半年後に、〇〇が△△になっている」の一文にします。

書き方の例：「半年後に、問い合わせから見積もりまでを、社長が手を離しても回せている」

お客さまが口にした言葉をそのまま使うと、あとで振り返るときに話が通じやすくなります。あわせて、目的に近づいたと判断する目安も決めておきます。

### 2. 業務の内容は、目的に効くものだけ 3〜5 つ

あれもこれもと並べるより、目的に直結するものに絞ると、毎月の手応えがはっきりします。

### 3. 「含まないこと」も契約書に書く

目的から外れたご相談は、内容と費用をお伝えして、合意してから別にお受けします。脱線をいちばん抑えてくれるのは、この取り決めです。

### 4. 毎回の打ち合わせのはじめに、目的を一言確かめる

議題を「目的に効くか」で振り分けます。外れた話は捨てずに「次の目的の候補」として預かっておくと、お客さまも安心して話せます。

### 5. 振り返りは目的に照らして、更新のときに目的を決め直す

月に一度、目的にどこまで近づいたかを一枚にまとめます。契約の更新の前に、目安に照らして振り返り、次の期間の目的を決め直します。

## キットでの回し方

| いつ | すること | キットのどこで |
|---|---|---|
| 最初の面談のあと | 面談のメモから目的の候補を出し、お客さまと一つに絞る。決まったら「目的カード」にする | カルテの「メモ」に目的カードを貼る（[PROMPT.md](../PROMPT.md) の「契約の前に、お客さまの目的を一つに絞るとき」） |
| 契約 | 目的・目安・業務の内容・含まないことを入れて契約書を作る | 電子契約のひな形 `komon-mokuteki` |
| 毎回の打ち合わせのあと | 話したことを目的に照らして振り分け、議事録と TODO を残す。外れた話は「次の目的の候補」に | カルテの「やりとり（面談）」に議事録、「フォロー」に TODO、「メモ」に次の目的の候補（PROMPT.md の「打ち合わせのあとに、目的に照らして記録するとき」） |
| 月に一度 | 目安に照らして、どこまで近づいたかを一枚にまとめる | カルテの「メモ」 |
| 更新の前 | 振り返りを踏まえて、次の期間の目的を決め直す | 新しい目的カードをメモに貼り、必要なら新しい契約書を作る |

## `komon-mokuteki` の条文の骨組み

| 条 | 中身 |
|---|---|
| 第１条（目的） | お客さまの目的と、近づいたと判断する目安。進め方は目的に照らして決める |
| 第２条（業務の委託） | 目的に効く業務の内容（5 つまで）、打ち合わせのはじめに目的を確かめること、含まないこと、報酬と支払い |
| 第３条（業務の遂行） | 目的から外れるご依頼は、範囲・費用・期間を示して合意してから、別に行う |
| 第４条〜第７条 | 助言の性質・知的財産・損害賠償・秘密保持 |
| 第８条（契約期間） | 期間と自動更新 |
| 第９条（目的の見直し） | 満了の前に目安に照らして振り返り、更新するときは次の期間の目的を決めて書面で確かめる |
| 第１０条（協議） | 定めのないことは協議で決める |

同梱の契約書の文面は見本です。実際に使う前に、必要に応じて専門家に確かめてください。
