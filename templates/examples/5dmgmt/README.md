# 電子契約の見本ひな形

| id | 名前 | 向いている使い方 | 個人対応 |
|---|---|---|---|
| `ai-keiei` | 見本：AI経営実装 | AIを活用した経営の仕組みづくりを継続支援するとき | なし |
| `kobetsu` | 見本：個別見積り | 面談で合意した業務内容と報酬を個別に定めるとき | なし |
| `ai-katsuyo` | 見本：AI活用サポート（対面講義つき・期間限定） | 対面講義を含む期間限定のAI活用支援を行うとき | なし |
| `komon` | 見本：経営コンサルティング（着手金＋月額） | 集中講座を含む着手金と月額報酬の顧問支援を行うとき | あり |
| `komon-gekkan` | 見本：顧問（月額・基本契約・自動更新） | 着手金なしの月額顧問を基本契約として結ぶとき | あり |

使うときは `templates/contracts/` にフォルダごと写し、`schema.json` の `id` を新しいフォルダ名に合わせてください。文面は見本なので、必要に応じて専門家に確かめてください。
